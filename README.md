# Keasa Chandana – Resume Website

A simple responsive personal resume website built with HTML, CSS and a small amount of JavaScript. No frameworks or installation are required.

## Files
- `index.html` – resume content
- `style.css` – layout and responsive styling
- `script.js` – automatically displays the current year

## Run on your computer
1. Download or clone this repository.
2. Open the folder.
3. Double-click `index.html` to open it in your browser.

## Publish using GitHub Pages
1. Create a GitHub repository named `keasa-chandana-resume` (or another name).
2. Upload `index.html`, `style.css`, `script.js` and this README to the repository's root.
3. Open the repository's **Settings**.
4. Select **Pages** from the left menu.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait a few minutes. GitHub will show your website URL in the Pages section.

Your URL will look like:
`https://YOUR-GITHUB-USERNAME.github.io/keasa-chandana-resume/`

## Before publishing
- Check that your phone number and email address are correct.
- Consider removing your full street/locality address and phone number from a public website. You can use only `Hyderabad, Telangana, India` and an email/contact form instead.
- Verify certificate names and issuing organisations against the original certificates.
- Keep project descriptions accurate. Do not describe an academic concept as a clinically validated mental-health diagnostic system.
- Add a PDF resume link only if you are comfortable making that PDF publicly accessible.

## Add your PDF resume (optional)
Put a copy named `Keasa-Chandana-Resume.pdf` in this same folder/repository. Add this link in `index.html` where you want it:
`<a href="Keasa-Chandana-Resume.pdf" target="_blank" rel="noopener">Download PDF Resume</a>`

Only upload a PDF you are comfortable making public.
